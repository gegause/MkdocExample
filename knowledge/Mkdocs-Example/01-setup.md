# 1. Project Setup

This guide walks you through preparing a GitHub repository to host a documentation site built with MkDocs.

## What You Need

- A GitHub account
- Python 3.8+
- Basic familiarity with Markdown
- A repository containing Markdown files (this example uses a folder named `knowledge`)

## 1. Create or Clone the Repository

If starting fresh:

git clone https://github.com/<your-user>/MkdocExample
