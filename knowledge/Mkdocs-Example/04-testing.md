# 4. Testing Your MkDocs Site

After deploying, verify that everything is working correctly.

## 1. Confirm the `gh-pages` Branch Exists

In GitHub:

- Go to **Branches**
- Look for a branch named `gh-pages`

If it exists, deployment succeeded.

## 2. Verify GitHub Pages Settings

Navigate to:

**Settings → Pages**

Ensure:

- Source = `gh-pages`
- Folder = `/`

GitHub should show a green confirmation banner with your published URL.
